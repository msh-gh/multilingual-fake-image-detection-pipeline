During my 3 2 semester, I developed a multilingual fake image detection pipeline. The system combines BLIP for caption generation, YOLO for scene graph extraction, and CLIP for embedding verification to detect semantic inconsistencies in images. I added multilingual caption validation (English/Hindi) and built a classifier to flag semantic drift. This approach enables robust detection of forged images that evade pixel level detectors by focusing on semantic verification across captions, scene graphs, and embeddings. I also ensured end to end robustness with preprocessing, multilingual support, and lightweight testing, making the pipeline effective against subtle, artifact free forgeries.
